# 一手評価 AI によるコミの推定（2026-10-21）

4 手探索の導入前に配信していた一手評価 AI の重みで自己対局を行い、先手・後手の得点差を調べました。探索版との比較は [探索 AI の評価](SEARCH-AI.md) を参照してください。各盤 20,000 局、全 6 種類で **120,000 局**です。

コミを除いた黒の得点差の平均は約 3〜7 目、中央値は球面で 0 目、トーラスで 1 目でした。黒の大勝が平均を押し上げており、平均得点差と勝率を均すコミは一致しません。現在のコミ 6.5 では黒の勝率が約 14〜24% で、この AI 同士の対局では後手有利でした。

## 得点差と現在のコミでの勝率

得点差は「黒の面積得点 − 白の面積得点」で、コミを含みません。区間は後述の乱数系列の組を単位にした推定です。

| 盤 | 黒の平均得点差（95% 区間） | 得点差の中央値（95% 区間） | コミ 6.5 の黒勝率 |
| --- | ---: | ---: | ---: |
| 球面・小（56 点） | 3.63 目（3.19〜4.07） | 0 目（0〜0） | 21.9% |
| 球面・標準（98 点） | 4.08 目（3.48〜4.67） | 0 目（0〜1） | 20.7% |
| 球面・大（152 点） | 2.91 目（2.41〜3.42） | 0 目（0〜0） | 14.3% |
| トーラス 7×7 | 3.72 目（3.36〜4.09） | 1 目（1〜1） | 18.6% |
| トーラス 9×9 | 6.94 目（6.30〜7.59） | 1 目（1〜1） | 23.8% |
| トーラス 11×11 | 5.88 目（5.16〜6.61） | 1 目（1〜1） | 17.4% |

中央値は、得点差分布の真ん中を示します。平均得点差の分だけ白にコミを与えると、必ず勝率が五分になるという意味ではありません。

## 勝率を五分にするコミをどう読むか

球面では、測定時点の設定候補（0.5、1.5、…、9.5）の中では **0.5 目**が最も五分に近くなりました。ただし小さい球面では、それでも黒勝率は約 42% です。

トーラスでは **1 目**に得点差が集中しています。0.5 目から 1.5 目に変えるだけで、その対局群がまとめて黒勝ちから白勝ちに変わります。そのため、測定時点の設定候補だけでは五分に近づけにくい結果でした。

| 盤 | コミ 0.5 の黒勝率 | コミ 1.5 の黒勝率 |
| --- | ---: | ---: |
| 球面・小（56 点） | 42.1% | 35.9% |
| 球面・標準（98 点） | 49.4% | 46.2% |
| 球面・大（152 点） | 47.8% | 46.9% |
| トーラス 7×7 | 81.1% | 25.2% |
| トーラス 9×9 | 68.9% | 33.5% |
| トーラス 11×11 | 67.0% | 33.5% |

整数コミを許して引き分けを半勝として数えると、トーラスのコミ 1 は次のようになります。測定時点のアプリの設定には整数コミはありませんでした。

| 盤 | 黒勝ち | 引き分け | 白勝ち | 黒の得点率（勝ち 1、引き分け 0.5） |
| --- | ---: | ---: | ---: | ---: |
| トーラス 7×7 | 25.2% | 55.8% | 18.9% | 53.1% |
| トーラス 9×9 | 33.5% | 35.3% | 31.1% | 51.2% |
| トーラス 11×11 | 33.5% | 33.5% | 33.1% | 50.2% |

したがって、この AI 同士で勝率を均す目安は球面で 0〜0.5 目付近、トーラスで約 1 目です。整数得点への集中があるため、固定のコミだけで厳密な 50% にできるとは限りません。この測定ではアプリの設定や初期コミは変更していません。

## 測定方法

- 使用した重みは `Params::tuned()` / 配信用 WASM の `AI_WEIGHTS` と同一です。通常のノイズ 0.7 を含めます。
- 各盤で独立な乱数 seed の組を 10,000 組作り、1 組につき 2 局対戦します。2 局目では黒と白に割り当てる乱数系列を入れ替えます。同一 AI 同士なので、入れ替えるのは重みではなく乱数系列です。
- ブラウザの WASM と同様、手番ごとに新しい 32-bit seed を与え、その手の評価用乱数を生成します。
- 初期局面は空の盤です。コミは 0 で対局し、最終得点に後からコミを適用して勝率を集計します。現在の AI はコミを着手評価に使わないため、コミごとに打ち直す必要はありません。
- 黒白が続けてパスしたときの面積得点を使います。死に石の除去などは行いません。
- 安全のため交点数の 20 倍を手数上限にしましたが、**打ち切りは全盤で 0 局**でした。
- seed は `20261021`。盤と対戦組の番号から各乱数系列を決定します。16 並列で、120,000 局の実行時間は約 **26.53 秒**でした。画面の 400 ms 待機は測定に含みません。

平均得点差と勝率の 95% 区間は、2 局の組ごとの平均の分散から正規近似で計算します。中央値の区間は、組を単位とした 2,000 回のブートストラップによる 2.5%・97.5% 点です。単純に 20,000 局すべてを独立とみなす計算はしていません。

各盤の最初の 2 局、計 12 局について、同じ手番 seed を配信用 WASM に渡し、**1,201 手すべての選択手の一致**を確認しました。JS のルールで全手順を再生し、終局と最終得点差も一致しています。

## 再実行とデータ

実行時のソースのコミットは `147f969`。測定用スクリプトはこの記録と同時に追加しています。Rust 1.99.0 と Node.js v26.7.0 で実行しました。

PowerShell ではリポジトリ直下から次のように実行します。

```powershell
node -e "require('node:fs').mkdirSync('tools/ai-tuner/target/komi-study',{recursive:true})"
rustc --edition 2021 -C opt-level=3 -C lto=fat -C codegen-units=1 -A dead_code tools/ai-tuner/komi-study.rs -o tools/ai-tuner/target/komi-study/komi-study.exe
.\tools\ai-tuner\target\komi-study\komi-study.exe 10000 20261021 tools/ai-tuner/target/komi-study/scores.json
node tools/ai-tuner/komi-study.mjs
```

[komi-study.rs](komi-study.rs) が自己対局を行い、[komi-study.mjs](komi-study.mjs) が集計と WASM / JS での一致確認を行います。

- [komi-scores.json](experiments/2026-10-21/komi-scores.json)：全対戦組の得点差と、検証用の代表棋譜。
- [komi-summary.json](experiments/2026-10-21/komi-summary.json)：得点差の度数分布、コミ別の勝率・引き分け率、区間推定、ソースと配信 WASM の SHA-256。

これは現在の AI の打ち方に依存する自己対局での推定です。人間同士や、より強い AI で対局したときの適正コミ、盤そのものの理論的な先手有利を示す値ではありません。
