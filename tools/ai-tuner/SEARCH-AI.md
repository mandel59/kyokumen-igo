# 探索 AI の実装と、コミ推定の再検証（2026-10-21）

この文書は手作業の係数で実装した初版の記録です。その後の係数の最適化と現行版の検証は [4 手探索のチューニング記録](SEARCH-TUNING.md) を参照してください。

旧一手評価 AI で得たコミの目安は、その AI の打ち方に強く依存していました。新しく実装した 4 手探索 AI では、同じコミ 6.5 の自己対局でも黒勝率が大きく変わっています。「旧 AI が真の先手有利を見落とした確率」を数値化することはできませんが、旧 AI の自己対局結果だけから適正コミを決める根拠は不足していました。

4 手探索版は、選定に使っていない seed で旧 AI と **6,000 局**対戦し、**65.6%** 勝ちました。95% 区間は **64.5%〜66.8%** です。相対的な強さの改善を確認したため、この時点で WASM を利用できるアプリへ探索版を採用しました。初期コミや選べる範囲は変更していません。

## 旧 AI への疑いと検証の意味

旧 AI の得点分布には、小さい球面で全盤が片方の得点になる対局が約 32%、7×7 トーラスで 1 目差になる対局が約 56% ありました。これだけで誤りを証明することはできません。面積方式・死に石を除去しないルールの性質も含まれます。

一方、旧 AI は相手の応手を読まず、コミを着手選択に使いません。平均と中央値の差や大量の 0〜1 目差に、方針固有の偏りが含まれる可能性を調べるため、別の評価関数と探索を使って比較しました。

旧 12 万局の区間推定が表すのは、固定した AI における乱数のばらつきです。AI の方針を変えたときの偏りや、最善手同士での先手有利まで含めた信頼区間ではありません。

## 実装した探索

[src/search.rs](src/search.rs) の候補限定 alpha-beta 探索です。通常の囲碁盤だけでなく、既存の球面・トーラスのグラフ上で同じルールを使います。枝刈りの基本的な考え方は [Knuth / Moore の alpha-beta 解析](https://www.sciencedirect.com/science/article/pii/0004370275900193) に対応しますが、今回の実装では候補を絞るため、全合法手の最適性を保証しません。

- 自分と相手の着手を合わせて最大 4 手を読みます。
- ルートは上位 12 候補、その後は上位 6 候補を調べ、各節点でパスも候補に含めます。
- 候補の順位は取り・アタリの石の救出・呼吸点などで決めます。ルートでは seed による少量のゆらぎを加えます。
- 非終局の評価は盤上の石、距離 1〜3 の勢力、呼吸点の少ない連の危険度、コミを使います。終局ではアプリと同じ面積得点を使い、勝ち・引き分け・負けを区別します。
- 勝てる状況で相手がパスしたら終局を選べます。負ける終局は避けるため、コミによってパス判断が変わります。
- 取り・自殺手・位置的スーパーコウは既存の Rust `Game` で検証します。実際に対局へ着手を適用する際は、従来どおり UI 側の JS のルールが最終確認します。

評価の係数は手作りで、学習済みモデルは使いません。旧 `Params::tuned()` の重みとは別の評価です。深い死活や、探索幅から外れた妙手を読める保証はありません。

## 試走と、選定後の独立検証

まず seed `20261022` で深さを比較しました。以下は選定用の試走であり、最終的な勝率の推定には使っていません。

| 読む深さ | 旧一手評価 AI との試走局数 | 探索版の勝率 |
| --- | ---: | ---: |
| 1 手 | 240 | 17.5% |
| 2 手 | 240 | 44.2% |
| 3 手 | 120 | 42.5% |
| 4 手 | 240 | 70.4% |

1〜3 手の版は安定して改善せず、4 手の版を独立検証に進めました。静的評価と浅い読みの組み合わせにも偏りがあり、「探索を追加しただけで強くなる」とは言えない結果でした。

独立検証では seed `20261023`、各盤 1,000 局、先後を同数にしてコミ 6.5 で対戦しています。各対戦組では、AI とそれに与える乱数系列をセットで先後交換します。

| 盤 | 4 手探索版の対旧 AI 勝率（95% 区間） |
| --- | ---: |
| 球面・小 | 71.8%（69.1%〜74.5%） |
| 球面・標準 | 64.4%（61.5%〜67.3%） |
| 球面・大 | 67.8%（65.0%〜70.6%） |
| トーラス 7×7 | 69.3%（66.7%〜71.9%） |
| トーラス 9×9 | 61.8%（59.0%〜64.6%） |
| トーラス 11×11 | 58.7%（55.9%〜61.5%） |

全 6 種類の盤で改善しました。別 seed `20261024` で 2 手探索版とも計 600 局対戦し、4 手探索版が **73.3%**（95% 区間 69.8%〜76.9%）勝っています。

## コミを変えた自己対局

4 手探索版同士をコミ 0・1・3.5・6.5 で、それぞれ各盤 200 局、計 4,800 局対局させました。2 手版同士もコミ 1・6.5 で各盤 200 局、計 2,400 局測っています。seed は `20261024` です。

探索版はコミを終局の勝敗評価に使うため、各コミで実際に対局し直しています。旧一手 AI のように同じ棋譜へコミを後付けする比較ではありません。

### コミ 6.5 の黒勝率

| 盤 | 旧一手 AI（各 20,000 局） | 2 手探索（各 200 局） | 4 手探索（各 200 局） |
| --- | ---: | ---: | ---: |
| 球面・小 | 21.9% | 52.5% | 45.0% |
| 球面・標準 | 20.7% | 52.5% | 44.0% |
| 球面・大 | 14.3% | 53.5% | 51.5% |
| トーラス 7×7 | 18.6% | 39.0% | 36.5% |
| トーラス 9×9 | 23.8% | 50.5% | 48.5% |
| トーラス 11×11 | 17.4% | 50.5% | 39.0% |

4 手版の黒勝率の 95% 区間は、盤によって幅が片側約 6.5〜7.3 ポイントあります。標本数の差に注意が必要ですが、全盤で旧 AI の結果から大きく変わりました。

### 4 手探索同士のコミ別得点率

以下は黒勝ちを 1、引き分けを 0.5 とした黒の得点率です。

| 盤 | コミ 0 | コミ 1 | コミ 3.5 | コミ 6.5 |
| --- | ---: | ---: | ---: | ---: |
| 球面・小 | 55.8% | 52.0% | 47.5% | 45.0% |
| 球面・標準 | 51.2% | 49.8% | 45.5% | 44.0% |
| 球面・大 | 55.5% | 54.0% | 53.5% | 51.5% |
| トーラス 7×7 | 70.8% | 55.8% | 38.5% | 36.5% |
| トーラス 9×9 | 64.0% | 57.0% | 48.5% | 48.5% |
| トーラス 11×11 | 51.2% | 45.8% | 40.5% | 39.0% |

前回の「球面 0〜0.5 目、トーラス約 1 目」という目安を、盤そのものの適正コミとして使う根拠はありません。一方、今回も探索の深さで結果が異なり、標本数も各条件 200 局です。4 手版の結果から新しい適正コミを確定することもできません。さらに強い独立した方針や探索量で、結果が安定するかを調べる必要があります。

## 測定条件と確認

試走 840 局、独立した対戦検証 6,600 局、探索版同士のコミ評価 7,200 局、計 **14,640 局**を行い、手数上限（交点数の 20 倍）による打ち切りは全条件で 0 局でした。

対局は空盤から開始し、各手で新しい 32-bit seed を生成します。勝率・得点率の区間は、先後交換した 2 局の平均を単位にした正規近似です。全盤の対戦勝率は盤を層として合成しています。試走の seed と独立検証の seed を分け、独立検証後に係数を調整していません。

Rust の戦術テストでは、取り、スーパーコウ、終局の勝ち・負け・引き分け、コミに応じたパス、状態の非破壊性を確認しました。この時点の `search-tests.mjs` は独立検証の代表 12 局を同じ seed で配信 WASM に再現し、計 1,216 手（うち探索 609 手）の選択と、JS で再生した最終得点の一致を検証しました。現行の [search-tests.mjs](../../search-tests.mjs) は調整後の係数に対応する代表棋譜を使います。

## アプリでの実行時間

Windows / AMD Ryzen 7 3700X、Node.js v26.7.0 上で、既存の 300 局面を使いました。各盤 50 局面を 2 周ウォームアップし、異なる seed で 5 周、各 250 回測っています。入力検証・転送・履歴からの局面復元・探索を含み、Worker の通信や描画は含みません。

| 盤 | 中央値 | 95 パーセンタイル | 最大 |
| --- | ---: | ---: | ---: |
| 球面・小 | 2.54 ms | 4.41 ms | 6.32 ms |
| 球面・標準 | 4.14 ms | 10.96 ms | 15.23 ms |
| 球面・大 | 7.43 ms | 14.85 ms | 18.98 ms |
| トーラス 7×7 | 2.67 ms | 5.61 ms | 9.14 ms |
| トーラス 9×9 | 4.05 ms | 8.02 ms | 15.40 ms |
| トーラス 11×11 | 7.10 ms | 19.11 ms | 24.88 ms |

配信 WASM は **57,096 bytes** です。通常はこの 4 手版を再利用する Worker 内で使い、最低 400 ms の手番表示を維持します。WASM が使えない場合は従来の一手評価で対局を続けます。低速な端末で同じ実行時間になる保証はありません。

## 再実行と保存データ

使用した既存コードのベースは `e04ab6e`。新しいソースと配信物の SHA-256、全条件の集計・区間推定は [summary.json](experiments/2026-10-21/search/summary.json) に保存しています。[同じディレクトリ](experiments/2026-10-21/search/) には各実験の全得点差と代表棋譜、WASM の全計測値があります。

PowerShell ではリポジトリ直下で実行します。

```powershell
node -e "require('node:fs').mkdirSync('tools/ai-tuner/target/search-study',{recursive:true})"
rustc --edition 2021 -C opt-level=3 -C lto=fat -C codegen-units=1 -A dead_code tools/ai-tuner/search-study.rs -o tools/ai-tuner/target/search-study/search-study.exe
.\tools\ai-tuner\target\search-study\search-study.exe 4 0 500 6.5 20261023 tools/ai-tuner/target/search-study/heldout-d4-greedy.json
# 自己対局は 4 4、浅い版の比較は 4 2 を指定。第 4 引数がコミ。
node tools/ai-tuner/build-wasm.mjs
node search-tests.mjs
node wasm-tests.mjs
node tools/ai-tuner/bench-search.mjs
```

[search-study.rs](search-study.rs) は初版の係数（`search::Params::legacy()`）を固定して、当時の比較対局を再現します。[search-summary.mjs](search-summary.mjs) は保存済みの実験データと速度測定を集計します。人間との棋力比較や、盤の理論的な適正コミの証明は今回の評価に含みません。
