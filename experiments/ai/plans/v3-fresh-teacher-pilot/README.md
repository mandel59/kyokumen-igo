# 新規教師の予備実験

2026年10月28日実施。補助方策学習を事前基準で終了した後、新しい教師データ収集へ進めるかを確認する。

事前条件は [plan.json](plan.json)。KataGo512の6局面平均が0.5秒以下、現在のv3・64訪問に対し平面7/9/11路の先後交換各4局で全体75%以上かつ各盤50%以上。全棋譜と教師の来歴を保存し、予備対局は学習に使わない。

結果は平均0.244秒/局面、12勝0敗、打ち切り0で通過。少数局の教師選定であり、v3の改良や一般的な棋力を証明する結果ではない。次の比較は [新規データ実験](../v3-fresh-data-study/README.md)。
