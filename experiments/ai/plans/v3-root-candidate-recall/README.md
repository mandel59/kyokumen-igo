これは前の会話で実施したseed 0・native CPUの局所診断です。元の対局時のモデル・乱数seed・バックエンドは棋譜から確定できません。優先度を人為的に変更した実験は、今回提案する候補生成方式の性能を示すものではありません。M0で生ログを再取得します。

## 戦術候補の仕様

C8plus4では、既存の合法手・スーパーコウ・確定勝敗・死に石打ち込み回避のマスクを通過した候補だけを扱います。上位8手は入れ替えず、その外側から追加します。パスは追加候補にしません。

候補となる着手は、着手後にその石の連が2個以上の呼吸点を持ち、次の合計点が正になるものです。

- 直ちに取る相手の石数。
- 着手前に呼吸点1〜2個だった味方の連のうち、その呼吸点に着手して、着手後の連が呼吸点2個以上となる連の石数。元の連ごとに一度だけ数えます。
- 直接隣接する異なる味方の連をつなぐ場合、その連数から1を引いた値。

合計点、元の事前確率、既存のseed付き根の順序の順で並べ、最大4手を追加します。2呼吸点から2呼吸点へのノビも含む候補生成上の目安であり、生存を証明したとは扱いません。元のlogit・事前確率・評価値にはボーナスを付けません。

これは、上位8手を保つこと、候補外だけから追加すること、2呼吸点の連も対象にすることが旧実験との違いです。グラフの隣接関係で実装し、座標・頂点番号・L6専用の処理は使いません。最大12手でも各候補を最低1回評価してから半減し、未評価の候補を評価済みとして扱わないことを確認します。

## 診断とデータ分割

[発端の棋譜](reported-game.json) は全体を開発専用とし、追加学習・診断の独立確認・独立対局の初期局面には使いません。seed 0〜7で候補入り・探索・最終選択を確認します。C8plus4が64訪問でL6を選ぶことは局所回帰の条件ですが、棋力向上の証拠には使いません。

別にA8で全9盤・各8局、計72局の新しい診断用対局を生成します。各局の盤上の点数Nに対し、floor(N/4)・floor(N/2)・floor(3N/4)・N手を着手済みの局面を固定抽出します。該当手数の前に終局した場合は欠測として残し、別局面に置き換えません。局番号0〜3を開発、4〜7を独立診断に固定し、同一対局の全局面・対称変換・再ラベルを同じ側に置きます。

平面の抽出局面だけを既存KataGo・4096訪問・同一ルールで解析します。曲面にはKataGoの教師ラベルを付けません。教師出力・バイナリ・設定・全履歴を保存します。独立診断の出力は候補選定・ハッシュ固定が終わるまで開きません。

記録する値は、初期候補と追加理由、候補集合が変わった割合、追加手を最終的に選んだ割合、教師最善手の候補入り率、候補内の教師方策の確率合計、候補入り後の教師最善手の探索・選択率です。各手の元の順位・事前確率・訪問数・Q・脱落段階・最終比較値も残します。候補取りこぼしと、候補入り後の評価・選択の失敗を分けて集計します。

## 採用基準

先後交換ペアを再標本化の単位とし、盤ごとに層化した10,000回のbootstrapで区間を計算します。採用にはすべての条件が必要です。

| 項目 | 基準 |
| --- | --- |
| 全9盤・288局 | 得点率55%以上、ペア95%区間の下限が50%超 |
| 平面3盤・96局 | 得点率55%以上、同下限が50%超 |
| 曲面6盤・192局 | 得点率50%以上、同下限が45%超 |
| 各盤 | 32局中14点以上 |
| 完走・整合性 | 違法手・手数上限到達0局、全履歴・終局値が一致 |

曲面と盤別の条件は劣化を検知するための基準です。各盤の観測得点だけで統計的な非劣性が証明できるとは主張しません。区間が基準に届かなければ、その実験では不採用です。結果を見て局数・seed・候補仕様を変更せず、必要なら別の計画を登録します。

速度は全9盤・各3局面の27通常局面と、発端局面・最大候補数・確定勝敗／パスの負荷局面を事前固定します。初期化・描画・診断ログを除き、履歴復元、候補生成、探索、推論、通常の待機を含め、2回warmup・7回計測・実行順交互で比較します。

CPU/WASMとWebGPUの双方で全体P95が基準の1.05倍以内、各盤および負荷局面が1.10倍以内を必要とします。Pixel 8aの実機WASM・WebGPU計測も配信反映前の条件です。未計測なら通過扱いにせず、反映条件を未完了として残します。

## 第2段階：方策の追加学習

第1段階で探索の効果を測定した後、新しい対局から通常局面と低順位の有力手を持つ局面を集めます。平面をKataGoでラベル付けし、曲面の代表的な教材も維持します。同じ局面・分割・勝敗／得点／所属ラベル・計算量で、教師方策による追加学習と、対照方策による追加学習を比較します。モデル規模は64チャネル・6ブロックのままです。

新モデルを現行探索と選定探索の両方で評価し、探索単独・学習単独・組み合わせの効果を報告します。第1段階の独立対局・独立診断・発端の棋譜は学習へ流用しません。

第2段階は後続計画です。教師データを作る前に、対局ID・局数・教材比率・教師訪問数・学習設定・モデル選定・独立評価の局数／seed／採用基準を別途固定します。第1段階の結果を見ながら学習条件を同時調整する運用は避けます。
