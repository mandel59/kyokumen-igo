## データをそろえて教師の効果を切り分ける

教師は[保存済みprofile](../../v3/2026-10-25-teacher-budget-4096/data/teacher-profile.json)のモデル・全候補WASM・4,096訪問・FPU1に固定します。コミは強さを確認済みの6.5とし、初期試験ではコミ拡張を加えません。自己対局の序盤だけ既存方式のDirichletノイズと温度を使い、ノイズなし再解析の教師目標と区別します。

各盤のgameIndex0〜5を学習、6〜7を検証と、生成前に決めます。学習36局、検証12局で、同じ起源対局の全局面・再解析結果を同じ側へ置きます。[game-split.json](game-split.json)に全48局のID・seed・分割を事前固定しました。以前の192局の強さ比較は学習へ流用しません。各対局の乱数は独立seedから作り、並列処理の順番で手順を変えません。IDにはモデル・探索WASM・予算・seed・盤・対局番号を含めます。

48局の全保存局面に対し、現行8候補64訪問と全候補4,096訪問の両方で再解析します。rootノイズを入れず、各目標は探索方策75%＋元NN事前分布25%です。両データで特徴・結果・分割・共通検証目標を同一にし、学習用方策だけを変えます。どちらかが確定負けなら両者の方策学習を対象外とし、WDL・得点・所有権ラベルは残します。

全候補のQ・訪問数・事前分布・root NNのWDLも保存します。completed-Q方式は別の仮説として後で比較できるようにし、この最初の2群比較へ途中追加しません。

## 生徒の学習と判定

両生徒は現行と同じ64幅・6層・120,905パラメータです。同じ初期重み、seed、サンプリング順、8epoch、batch32、学習率0.00003からcosineで0.000003へ、EMA0.99で学習します。過去の試験で勝敗予測が悪化したため、今回は学習率を抑える仮説を固定します。最適な設定と実証済みだという意味ではありません。

epoch0・4・8から、同じ通常局面・同じ教師目標の検証損失で選びます。強教師生徒だけを対局候補とし、対照生徒は追加学習の効果を区別する相手に使います。強教師生徒の選択epochが0より大きく、共通検証損失が初期モデルより低いこと、全体のWDL Brierが初期モデルの1.05倍以内、各盤の共通損失が1.10倍以内であることを進出条件とします。モデル容量だけを増やす試験は行いません。

対局は全員が同じ現行8候補探索・64訪問・FPU1です。強教師生徒対基準モデルと、強教師生徒対対照生徒を各96局で比較します。どちらも得点率60%以上、2比較を補正した97.5%区間の下限50%超、全盤8/16点以上、打切・違法手なしを必須とします。2比較は合算せず、独立した追試とも扱いません。

通過した同じ生徒を変更せず、新seedで基準モデルと192局の独立確認を行います。得点率55%以上、ペア95%区間の下限50%超、全盤16/32点以上、打切・違法手なしが基準です。盤別の半数以上は観測得点の基準であり、各盤の非劣性の証明ではありません。

速度は推論集約を使わない通常の実行で測ります。既存の[速度判定方式](../../v3/2026-10-25-root-value-scale/plan.json)を再利用し、18根局面・warmup2回・7反復、CPU/WASMとWebGPUでP95比が全体1.05倍以内・各盤1.10倍以内を確認します。

## 次の着手点と停止条件

最初に実装するのは、研究用のブラウザー自己対局生成と、同じ保存局面を2設定で再解析する処理です。既存のpooling・探索・学習部品を再利用し、まず65訪問の12局canaryと、各盤の固定局面で4,096訪問の通常/集約同値性を確認します。通過前に48局の本生成へ進めません。

違法手、ラベル不整合、分割漏れ、コード/入力の不意な変更、上限打切があれば段階を止めます。悪い結果の対局を別seedで置き換えず、途中成績を見て条件を変更しません。基準未達なら結果を保存し、新しい仮説は別計画にします。

出力先は新しいtools/ai-gnn/target/teacher-distillation-pilotです。既存の実験data/を上書きしません。通過しても成果物は研究用パッケージとし、この計画ではブラウザーモデルの設置、mainへのマージ、デプロイは行いません。
