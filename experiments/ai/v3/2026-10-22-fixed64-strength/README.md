# 共通64訪問のv3と現行v2の対戦

この評価条件では64訪問でもv3がv2を上回った。 76勝20敗0分、得点率79.2%、先後交換ペアによる95%区間は70.8%〜86.5%。打ち切りは0局だった。

## 条件

Pixel 8aの計測で採用したPC・スマートフォン共通の64訪問を評価した。実ブラウザーWorkerの専用WebGPUで、v3の現行重み・FPU 1・戦術と終盤の判定を使い、v2は現行WASM・深さ4とした。v3には時間制限を設定せず、敗北確定時を除く全4980手が厳密に64訪問だった。v2と同じ計算時間という意味ではない。

[事前計画](plan.json)を固定してから、全6盤・コミ6.5、各8組の先後交換、計96局を実行した。ランダムな合法4手から開始し、前回300ms評価と開始局面・手数ごとのseedを揃えた。seedは2026102260。機能確認の2局は勝率から除外した。結果を見て局数やモデルを変更していない。

## 計算時間と検証

PC上の平均着手計算時間はv3 33.91ms、v2 4.89ms。v3の敗北確定後の早期パスを除く平均は34.02ms。ブラウザー 155.0.4283.62、CPU AMD Ryzen 7 3700X 8-Core Processor。対戦の所要時間は201.31秒。これらはPCでの計算時間で、Pixel 8aの時間は[別の計測](../2026-10-22-pixel8a-visits/README.md)にある。

機能確認を含む98局の全棋譜を再生し、合法手・終局・得点・勝敗を照合した。評価96局の開始4手が過去の評価と一致すること、通常手が64訪問であること、入力コードと重みが実行中に変わっていないことを確認した。
