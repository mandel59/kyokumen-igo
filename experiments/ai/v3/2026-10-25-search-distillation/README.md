# 逐次半減探索の蒸留と方策サプライズ重点学習

強化の採用条件を満たさなかったため、現行の配信モデルを維持します。学習・教材生成の改善と候補・結果を保存します。

独立192局は **93勝99敗**（48.4%、先後交換ペアによる95%区間 41.1〜55.7%）。

## 実験条件

[事前計画](plan.json)の基準モデルは、コミット ebb82610 のモデル8e5b41e3974c・64訪問の逐次半減探索です。新旧どちらも64チャネル・残差6ブロック・120,905パラメータ・FPU 1・同じ探索WASMを使います。今回の比較対象は、既に逐次半減探索を採用したv3です。

保存済み自己対局288局・30,449局面を再現し、特徴量・合法手・最終結果を照合しました。各局の序中終盤から2局面ずつ、合計1,560局面にノイズなし64訪問の新しい教師を付けました。教師は探索方策75%・元のNN事前分布25%です。最終2候補への偏りを弱める今回の仮説であり、論文の保証をそのまま適用したものではありません。実際に打つ方策は平滑化しません。

既存の教師データも混ぜ、教師40%・自己対局60%、世代・盤・局・進行度を均等化しました。train/validationは以前のgameId分割を固定し、通常36,552局面を学習、8,129局面で検証しました。方策アンカー0.5、全ヘッド学習、lr3e-5→3e-6、EMA0.99、16epochです。epoch0/4/8/12/16の共通検証損失で選び、両候補ともepoch16となりました。

[KataGoの方策サプライズ](https://github.com/lightvector/KataGo/blob/master/docs/KataGoMethods.md#policy-surprise-weighting)を参考に、半分を元の再生・半分をKLに比例させる独立実装も比較しました。本実装は世代・盤ごとの質量を維持し、検証時の重みを変えません。コードの転載はありません。

## 再現と保存物

[manifest](manifest.json)に全データのSHA256、[データ構成](data/datasets.json)に元の不変データと新しい教師差分があります。リポジトリルートから node experiments/ai/v3/2026-10-25-search-distillation/data/rebuild-data.mjs NEW_DIRECTORY で、学習に使ったgzipをバイト一致で再構築できます。両入力の一致を確認済みです。元データは以前の学習改修アーカイブに保存されています。

学習コマンド・全チェックポイント・ONNX/FP32・golden・実行環境・基準モデル・検索WASM・全対戦棋譜を保存しました。対戦コマンドのdist/models/v3は実行時の基準モデルです。再実行時はdata/baseline-modelとdata/search.wasmを明示してください。source.patchは基準コミットへ適用する学習ツールと文書の差分です。

教材生成の実対局127手と再解析、全6盤の2/63/64/65訪問、旧PUCTの65訪問、合法分布・KL、Python13件、実プレイヤー回帰・実ブラウザーでのCPU/WebGPU一致とフォールバックが通過しました。最初の教材生成は0と-0の厳密比較で停止しました。数値としての0を照合するよう修正し、不完全出力を捨てて同じseedから全件再生成しました。
