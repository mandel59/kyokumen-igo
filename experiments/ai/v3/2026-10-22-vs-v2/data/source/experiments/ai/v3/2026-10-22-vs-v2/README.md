# 現行v2とv3の強さの比較

この評価条件ではv3がv2を上回りました。実Workerで現行アプリの設定を比較し、v3は91勝5敗0分、得点率94.8%でした。打ち切りは0局、先後交換ペアによる95%信頼区間は91.7%〜97.9%です。

## 評価条件

v3は現行重み`8e5b41e3974cbd30349fa483bb8a3a0f5c055ea9bb6cddef82c63b69b88b4b9a`、親平均FPU、WebGPU、1手300ms・最大4096訪問です。v2は現行配信WASM・盤別係数・深さ4です。双方ともアプリと同じ合法手・終盤判定を使います。v2は時間制限型ではないため、同じ計算時間という比較ではありません。UIの最低表示待ち400ms、描画、初期化、メッセージ転送は着手計算時間に含めません。

全6盤、コミ6.5、ランダムな合法4手から開始し、同じ開始配置と手数別seedで先後を交換しました。主比較は各盤8ペア・計96局、seed 2026102260、v3/v2を同一Worker内で交互に呼び出しています。他の計算ジョブを同時実行していません。補助比較はCPU ONNXのv3を128訪問、v2を深さ4に固定し、各盤4ペア・計48局、seed 2026102261で実行しました。訪問数とalpha-betaの深さは同じ探索量を表しません。

敗北確定で即時パスする手も上表に含みます。v3でその手を除いた平均は292.78msです。v2 APIは証明フラグや訪問数を返さないため、それらを比較しません。

ブラウザ155.0.4283.62、Node v26.12.1、CPU AMD Ryzen 7 3700X 8-Core Processor。主比較は24.04分、補助比較は3.37分でした。v3の全着手でWebGPU経路を検証しています。盤別の標本は全体より小さく、他の端末・コミ・人間への段級位には直接換算しません。
