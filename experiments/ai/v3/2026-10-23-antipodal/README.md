# 白の対蹠点コピーに対する現行AI

白の成績は対v2で38勝10敗（79.2%）、対v3で27勝21敗（56.3%）だった。補助手なしで真似だけを続けて白が勝ったのは、対v2で36局、対v3で9局。v3は48局中39局で対蹠点応手を違法にしたが、そのうち18局は白が補助手を使いながら勝った。今回の条件では、v2には対蹠点コピーがよく通用し、v3は真似を崩しても勝ち切れない場合がある。

黒v2は10勝38敗、黒v3は21勝27敗だった。各AI48局、打ち切りはv2 0局・v3 0局。白が補助手なしの対蹠点コピーだけで終えた局と、コピーが違法になって補助手を使った局は分けて解釈する。

## 条件

[事前計画](plan.json)を固定し、空の球面盤から、56・98・152交点の各盤で各AI16 seed、計96局を実行した。黒は現行v2 WASM・深さ4と、現行モデルのv3 WebGPU・厳密な64訪問。コミは6.5、上限は交点数の20倍の手数。黒のパスには白もパスする。白の対蹠点が合法なら必ずそこに打ち、違法な場合のみ、その1手を現行v2・深さ4で補い、次から真似を再開する。違法時のパス固定にはしていない。

試走2局を除いて96局を完了し、結果による局数追加・探索量変更・学習は行っていない。seedは2026102301を基準に盤サイズ・局番号から生成し、両AIで同じ手数ごとのseedを使う。ランダムな初期配置は入れていない。

補助手なしの成績はv2で黒0勝・白36勝、v3で黒0勝・白9勝。補助手を使った局の成績はv2で黒10勝・白2勝、v3で黒21勝・白18勝だった。

同じ空盤からのseed違いであり、重複棋譜もあり得る。独立した48種類の開始局面を評価したという意味ではないため、二項分布の信頼区間は付けない。全条件の個別数・コピーが違法になった理由と手数・コミ前の得点差は[集計JSON](data/summary.json)にある。

## 検証と実行環境

全98局（試走2局を含む）を再生し、合法手・取り・白の対蹠点対応・補助手の必要性・終局・得点・勝敗を照合した。通常のv3着手2943手が64訪問だった。対蹠点写像が隣接関係を保つこと、黒から一眼の大石を先に取って白の対蹠点応手を自殺手にできることも3サイズで確認した。[方策の事前検査](data/policy-checks.json)に件数がある。

実ブラウザーWorkerを使い、ブラウザー 155.0.4283.62、CPU AMD Ryzen 7 3700X 8-Core Processor で逐次実行した。評価の所要時間は139.33秒。端末速度を揃える評価やPixel 8a上の再測定ではない。
