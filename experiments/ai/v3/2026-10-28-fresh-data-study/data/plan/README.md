# v3の新規データ追加の比較実験

2026年10月28日、教師の速度・強さの予備実験を通過した後、本収集と学習の前に登録する。[plan.json](plan.json) を数値条件の正本とする。

現在の配信モデルを基準に、通常の追加学習Controlと、新規の平面教師データを追加したNewDataを比較する。推論規模、上位8候補・64訪問、学習更新回数、盤ごとの重み、検証局面を揃える。

新規収集は7/9/11路各8局の24局。各盤の半数はKataGo、半数は現在のv3の方策で対局を進め、ラベルは全てKataGo512から得る。半数は元棋譜のN/3手までの合法な履歴から分岐し、分岐は元の対局と同じ学習・検証区分に置く。初期棋譜の分岐前の局面は新規行として重複収録しない。予備対局・過去の独立評価・L6局面は使わない。

各盤6局を学習、2局を検証とする。NewDataの各平面は旧70%・新30%、曲面は既存データ100%。全9盤の重みは各1/9に保つ。Controlの学習には新規局面を入れず、両方式の共通検証には同じ新規検証局面も含める。

学習は両方式とも16epoch、各epoch9,263サンプル・145更新、計2,320更新。学習率1e-4→1e-5、EMA0.99。0/4/8/12/16epochから共通検証損失が最小の重みを選ぶ。この学習率・回数は以前の蒸留で使った条件を参照し、方式間では変えない。学習seedは1つのため、手法一般への結論には限界がある。

NewDataの共通検証改善0.1%以上・各盤損失1.02倍以内・推論検証を前提に、各方式72局を開発対局する。NewDataが40/72点以上、各盤3/8点以上、平面・曲面各50%以上、かつControlを上回った場合に限り、候補1つを新しい独立432局で評価する。採用には55%以上・ペア単位95%区間下限50%超・各盤19/48点以上・平面/曲面50%以上と速度・正確性の条件を全て必要とする。

収集24局、学習2回・32epoch、開発144局、独立最大432局を上限とする。打ち切りデータの差し替え、独立評価後の追加対局・候補変更・係数調整はしない。失敗時はこの実験を終了し、結果を保存する。

実行結果：24局の生成と全再生監査、2方式の学習・実Worker検証・開発144局を完了。NewDataは41勝31敗、平面18勝6敗、曲面23勝25敗。曲面50%以上とトーラス7路3/8点以上を満たさず終了し、独立評価には進まなかった。公開L6局面は4 seedでL6を選んだが、採用基準は変更していない。
