# v3 の再学習と診断対戦（2026-10-21）

初期 v3 の学習は 668 局面・3 epoch に留まり、固定探索回数での診断では v2 に 3 / 12 勝でした。教師データを増やして GPU で再学習し、同じ構成の旧モデルからの改善を確認しました。新モデルを `?ai=v3` の実験枠へ配置し、通常対局の v2 は維持しています。

## 学習

- アーキテクチャは変更なし：64 チャネル × 6 ブロック、120,905 パラメータ、ONNX 502,401 bytes。
- 新しい teacher seed 20261110–20261115、各 seed で全 6 盤・各 4 局。計 144 局・16,365 局面、打ち切り 0。
- 各盤のコミは 0 / 3.5 / 6.5 / 9.5 を含みます。教師は配信 v2 の深さ 4。
- 対局単位・盤別に分割：学習 120 局・13,633 局面、検証 24 局・2,732 局面。分割 seed 20261120。
- 30 epoch、batch 128、lr 0.001、AdamW。CUDA 13.0 版 PyTorch 2.14.1、RTX 5060 Ti で実行。
- 対戦結果を使って epoch を選ばず、検証損失が最小だった epoch 29 を選択。検証損失 2.7336。
- 検証局面で教師の着手を当てる率は top-1 37.3%、top-5 80.4%。勝敗ラベル正解率 71.3%。これらはモデル選択に使用した分割の値です。

生成・学習・最終対戦の seed、モデル選択方法、差し替えのガードは、学習前に [plan.json](data/plan.json) に記録しました。最初の 12 局の診断は計画作成前の観測です。

## 診断対戦

全 6 盤で合法な 4 手の初期配置を作り、同じ配置から先後交換します。コミ 6.5。GNN は 128 simulations を目安とするバッチ MCTS、v2 は配信版の深さ 4。終局評価の反復などにより、完了回数は 128 を少し超える場合があります。

**Node の CPU ONNX 推論による固定探索回数の比較であり、同じ実時間でのブラウザ棋力評価ではありません。** 対 v2 の旧モデル対照と新モデルには seed 20261140 の同じ配置・手番 seed を使いました。新旧の直接対戦は別の seed 20261130 です。

| 盤 | 旧 v3 対 v2 | 新 v3 対 v2 | 新 v3 対旧 v3 |
| --- | ---: | ---: | ---: |
| 球面・小 | 3 / 4 | 3 / 4 | 2 / 2 |
| 球面・標準 | 2 / 4 | 3 / 4 | 2 / 2 |
| 球面・大 | 1 / 4 | 3 / 4 | 0 / 2 |
| トーラス 7×7 | 1 / 4 | 4 / 4 | 2 / 2 |
| トーラス 9×9 | 2 / 4 | 2 / 4 | 2 / 2 |
| トーラス 11×11 | 1 / 4 | 3 / 4 | 2 / 2 |
| 合計 | **10 / 24** | **18 / 24** | **10 / 12** |

対 v2 の試走では 41.7% → 75.0%、新旧直接対戦では新モデルが 83.3%。全対戦は終局し、引き分け・打ち切りはありませんでした。旧版からの改善と、旧版に対する v2 対照の改善という実験枠の差し替えガードを満たしました。

盤別は 2–4 局に過ぎません。特に球面・大では新旧直接対戦が 0 / 2 であり、全盤での安定した改善を示す結果ではありません。初期モデルの 3 / 12 とは seed が異なるため、その値を新モデルの 18 / 24 と直接比較しません。人間に対する棋力・v2 への統計的な優越性・同じ実時間の優位は主張しません。

## ブラウザ確認

新モデルを配置後、Edge の Worker 内で WebGPU / WASM と PyTorch の出力を照合しました。最大絶対差は WebGPU 約 2.9e-6、WASM 約 3.8e-6。全 6 盤の探索、キャンセル、実際の Worker の `v3-webgpu` 選択と、既存 Worker / UI の回帰テストを通過しました。

モデル差し替え後のキャッシュ混在を避けるため、manifest を再検証し、モデルの取得 URL に SHA-256 を含めます。開いているページは再読み込みすると新モデルを読み込みます。

## 保存物・再現

[manifest.json](manifest.json) にソース・全保存物の SHA-256 を記録します。`data/` には計画、最初の診断、旧モデルの対照、新旧直接対戦、新モデル対 v2 の全棋譜、ブラウザ確認、モデル manifest、学習重み、6 seed 分の教師データ（gzip）、未コミット実装のパッチを保存しています。

学習器・CUDA のセットアップ、教師データ生成器、対戦コマンドは [開発手順](../../../../tools/ai-gnn/README.md) を参照してください。学習コマンドの条件は保存 manifest の seed・epoch・batch と plan に固定されています。所要時間の正確な計測は行っていません。対戦中は複数の試走を並行したため、記録された ms を速度比較に使いません。

今後はブラウザの同じ思考時間で、未使用 seed・より多い対局数・モバイル端末を含む独立評価が必要です。
