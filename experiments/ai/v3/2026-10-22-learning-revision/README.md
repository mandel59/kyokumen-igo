# v3の学習選抜と探索教師の比較

通常局面での学習と選抜を改修し、第1世代の重みを実験用v3へ採用しました。同じ探索・128訪問で旧重みに231勝153敗、独立評価の勝率は60.2%でした。64チャネル・6ブロック・120,905パラメータ、特徴量ABI 1の構造は維持しています。

## 変更内容と比較条件

以前の候補は、敗北確定後の強制パスを模倣することで検証損失が下がり、通常局面では悪化していました。今回は敗北確定局面を学習・選抜から除き、候補間で同じ検証教師を使い、旧重みへのKL制約を選抜指標に含めません。方策学習の対象局面を抽出した後も、旧教師と自己対局の損失比率を50/50に保ちます。

探索は未訪問手の初期評価を0とする従来方式と、親の実訪問平均を使う方式、その平均から訪問済み事前確率に応じて減算する方式を比較しました。重みを固定した開発対戦で親平均方式が56/96点、減算方式が51/96点となり、親平均方式を選びました。この開発結果は選択に使用しており、探索方式単独の独立評価ではありません。

ソースの基準は`69caea83f6d32e1b6d3cddba70f0b49916b68b40`、旧モデルは`e04f00bacc18ebf813095420ea015f2950de37aa8eaadc83b715b6fc126115f5`です。[ソース差分](data/source.patch)、[ソース一覧](data/source-manifest.json)、各コマンドの設定・ツールハッシュ・所要時間を保存しています。

[実行前の計画](plan.json)と[当初の計画](data/plan-at-start.json)に、探索比較・教師比較・世代更新・最終評価の条件を記録しました。学習前の監査で、旧教師の通常局面15,387件中160件の着手が既存の探索マスクで選べないと分かり、全候補でその着手損失だけを除外しました。勝敗・得点・所有ラベルは保持し、[変更理由と時刻](data/preprocessing-amendment.json)を残しています。

## 学習候補

第1世代は96局・10,253局面を生成しました。通常局面9,856件から同じ2,558件を抽出し、学習教師を3種類に変えて比較しました。全候補を同じ旧重みから開始し、12エポック、バッチ128、学習率1e-4から1e-5のcosine、EMA 0.99、旧重みへの方策KL係数0.5としました。0・4・8・12エポックを保存し、通常局面の共通512訪問教師で選抜しています。

| 方策教師 | 選択エポック | 共通検証損失 | 旧重みとの開発96局 |
| --- | ---: | ---: | ---: |
| 元の128訪問分布 | 8 | 2.9578 | 63勝33敗 |
| ノイズなし128訪問 | 8 | 2.9524 | 62勝34敗 |
| ノイズなし512訪問 | 12 | 2.9395 | 59勝37敗 |

全候補の初期共通損失は2.9960です。開発得点が最大の元の128訪問教師を選びました。候補間の数勝差から教師方式の優劣までは断定できません。深い教師ほど損失が低くても、対戦得点が高いとは限りませんでした。

第2世代は選択モデルで192局・20,196局面を追加しました。旧教師50%、第1世代自己対局25%、第2世代自己対局25%の重みで同じ条件の12エポックを学習しました。同じ第2世代検証集合で損失は3.0514から3.0174へ改善しましたが、第1世代との開発対戦は48勝48敗、トーラス11は5/16点でした。事前条件の54/96点以上・各盤6/16点以上を満たさず不採用としました。世代間では検証集合が異なるため、第1世代と第2世代の損失値を直接比較しません。

## 独立評価と採用

選択済みの重みを固定してから、未使用seed 2026102250で384局を生成しました。全6盤、各32開始配置を先後交換、コミ6.5、ランダム開始4手、双方同じ親平均探索・128訪問です。強制パス・戦術判定も共通です。

| 盤 | 新モデルの勝利数 / 64局 |
| --- | ---: |
| 球面3 | 36 |
| 球面4 | 38 |
| 球面5 | 45 |
| トーラス7 | 34 |
| トーラス9 | 38 |
| トーラス11 | 40 |

合計231勝153敗、打ち切り0局。盤別に層化し、先後交換した開始配置ペアを単位に10,000回bootstrapした95%信頼区間は55.5〜64.8%でした。事前条件の212/384点以上、各盤28/64点以上、区間下限が50%超をすべて満たしました。これは固定した6盤・開始配置分布・探索予算での旧重みに対する学習効果を示します。盤別の改善量の順位や対v2の強さは、この試験だけでは確定しません。

実Worker・WebGPUでは、新重みと親平均探索を、旧重みと従来探索に1手300ms・各盤4開始配置の先後交換で比較しました。seed 2026102252、48局で32勝16敗、打ち切り0局でした。この少数対局は実時間での統合確認として扱います。ウォーム推論は6盤×バッチ1/4/8、モデルあたり1,080回の測定でP95が双方4.1ms、比率1.00でした。

採用モデルは`8e5b41e3974cbd30349fa483bb8a3a0f5c055ea9bb6cddef82c63b69b88b4b9a`です。全条件通過後に`dist/models/v3`へ反映しました。強制パスを除いた検証でも、パス適合率は80.0%から71.6%に下がっており、全指標が改善したわけではありません。対v2の同時間評価やモバイル端末での速度は別途検証が必要です。

## 所要時間と検証

探索比較開始から最終採用まで約3.90時間でした。第1世代の自己対局約13.3分・再解析約14.6分、第2世代の自己対局約22.5分・再解析約4.3分・学習約2.2分、最終384局約48.2分、実ブラウザ48局約23.8分です。CPUはRyzen 3700X、学習はCUDA対応GPU、最終ブラウザはEdge 155を使用しました。コマンド別の正確な値と実行環境は各記録に保存しています。

Rust探索、学習の損失・分割・正規化、全6盤のONNX/WASM、既存終盤棋譜、実WebGPUの出力一致・バッチ・フォールバック・キャンセル・本番Worker・UIの検証を通過しています。参考資料とライセンスは[第三者目録](../../../../docs/third-party/catalog.json)へ記録しています。

## 保存データと再現

[集計](data/summary.json)、[採用判定](data/selection.json)、[第1世代](data/execution.json)、[第2世代](data/second-generation.json)、[成果物目録](manifest.json)に、全候補・チェックポイント・学習入力・棋譜・ハッシュ・実行コマンドを保存しています。rootの計画はmanifestのplan、data内の全ファイルはartifactsで検証します。モデルパッケージのmanifestと実験のmanifestは別です。

リポジトリ直下で、保存データと目録を検証できます。

```powershell
node tools/ai-tuner/check-experiments.mjs
node tools/third-party.mjs
node tools/check-third-party.mjs --prepared
```

各`*-command.json`のcommand・argsが実際に使用した設定です。再学習では[学習環境](../../../../tools/ai-gnn/README.md)を用意し、`uv run --project tools/ai-gnn --extra cuda python ...`で実行します。追試の出力は新しい実験ディレクトリへ保存し、過去の入力・結果を上書きしません。今回の`run-*-study.mjs`等は当該実験の固定パスと上書き拒否を持つため、そのまま再実行する用途には使いません。
