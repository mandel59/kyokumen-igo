# v3の複数方式による改善試行

2026年10月28日実施。**探索6案と学習5案、計11条件**を試しました。今回の試行から配信へ採用する候補は残りませんでした。元のv3を維持しています。

[最終判定](data/scope/results/decision.json) と、各実験の計画・モデル・全対局・探索診断・学習履歴・実行コマンドを保存しました。

## 探索方式の比較

同じモデル、全9盤、64訪問で、6条件を各36局、計216局比較しました。教師との開発用一致率も確認しましたが、選定は事前登録した対局条件で判定しました。

| 方式 | 対A8の成績 | 平面 | 曲面 |
| --- | --- | ---: | ---: |
| Q02 | 17勝19敗 | 41.7% | 50.0% |
| Q08 | 18勝18敗 | 58.3% | 45.8% |
| Skip16 | 17勝19敗 | 66.7% | 37.5% |
| Tactical8 | 17勝19敗 | 33.3% | 54.2% |
| TacticalFast | 17勝19敗 | 41.7% | 50.0% |
| PUCTQ | 16勝20敗 | 33.3% | 50.0% |

Q02/Q08は根のQ係数を変更、Skip16は上位16手を一度評価して早く4手へ絞る方式、Tactical8は最大8候補のまま戦術手を採用、TacticalFastは前の候補追加方式を軽量化、PUCTQは根をPUCTで探索して訪問済みのQと事前確率で最終手を選ぶ方式です。

すべて20/36点の予備通過条件に届かず、追加比較・独立評価には進んでいません。これは少数局の探索的比較であり、各方式が統計的に弱いと確定したという意味ではありません。[予備集計](data/search/results/screen-summary.json) と [選定](data/search/results/screen-selection.json) を参照してください。

元の発端局面ではSkip16、Tactical8、TacticalFast、PUCTQがL6を選びましたが、局所の解決だけでは総合的な強さを示せませんでした。既存の開発用48平面局面を使った教師一致の診断も保存しています。過去の未使用の独立診断は開いていません。

## 学習方法の比較

元の教師データと対局単位の分割を維持し、120,905パラメータ・64チャネル・6ブロックを固定しました。既存の学習9,263局面・検証3,123局面を使い、8epoch、AdamW、学習率3e-5から3e-6へのcosine、EMA0.99、2epochごとの共通検証とepoch0を含む選定を登録しました。

HeadUniform/HeadPriorityは着手・パスの4,482パラメータだけを学習、AllUniform/AllPriorityはネット全体を学習、ValueUniformは勝敗評価の4,867パラメータだけを学習する条件です。Priorityは元のモデルと教師のKLを学習局面だけで再計算し、75%の均等化した教材と25%の食い違いを重視した教材を混ぜます。検証側の重みは共通です。

| 条件 | 共通検証損失の相対改善 | 選択epoch | 判定 |
| --- | ---: | ---: | --- |
| HeadUniform | 0.006% | 8 | 検証基準未達 |
| HeadPriority | 0.044% | 4 | 検証基準未達 |
| AllUniform | 0.559% | 8 | 対局比較へ |
| AllPriority | 0.562% | 8 | 対局比較へ |
| ValueUniform | 0.044% | 8 | 検証基準未達 |

共通検証損失0.1%以上の改善、各盤の損失が基準の1.02倍以内、epoch0以外の選択を進行条件にしました。部分学習では対象外の重みが完全一致することも確認しました。モデル選定に使った古い検証分割の改善を、独立な棋力の証明とは扱っていません。

追加学習モデルの発端局面も診断しました。AllUniformではL6の順位は14位から11位へ上がりましたが、8候補には入らず、4種類のseedともJ3を選びました。この個別の見落としは残っています。data/scope/results/reported-game-diagnostic.jsonに記録し、診断を見てモデルを再調整していません。

独立評価の平面は63勝81敗（43.8%）、曲面は159勝129敗（55.2%）でした。平面7路は18勝30敗で、盤別の最低19/48点にも届きませんでした。全体の95%区間が50%を含み、今回の独立評価で強化を確認できないため不採用です。独立評価後に別モデルへ差し替えたり、好成績の盤だけを選んで配信したりしていません。

## 速度・検証・制約

通常局面のP95比は全体1.05以内・各盤1.10以内を基準としました。短い負荷局面は新しい計画の測定前に31回計測とmax(基準の1.10倍、基準+2ms)を登録しました。前の実験の不採用判定を遡って変更するものではありません。速度を測定した場合の全試行・環境と採否はdata/scope/resultsに保存しています。

探索7条件（基準を含む）それぞれのRust13テストと、全9盤・5予算の315件の意味論チェックが通過しました。追加した部分学習と優先再生を含む学習テスト16件が通過しました。AllUniformとAllPriorityは実際のEdge WorkerでCPU/WebGPUの数値整合、全9盤、キャンセル、フォールバックの検証を通過しました。全対局の再生監査は各studyのresults/replay-audit.jsonにあります。

計測はPC上です。スマートフォンでの速度・対局成績は測定していません。native CPUの固定訪問数による対局成績を、人間向けの段級位や全端末での同時間比較としては扱いません。
