# Kyokugo AI v1

Kyokugo AI v1 は、合法な着手を評価関数で採点し、一手を選ぶアーキテクチャです。相手の応手を含む木探索は行いません。

## 評価と実装

取り、アタリの石の救出・捕獲、呼吸点、隣接石、混雑・開けた場所、石の勢力を評価し、少量の乱数を加えます。簡単な眼を埋める手を避け、最高評価が閾値未満ならパスします。学習済みモデルは使いません。

- 比較用JS：[legacy-v1.mjs](../../../tools/ai-tuner/legacy-v1.mjs) の chooseMove / AI_WEIGHTS。アプリには読み込まない
- Rust：[src/ai.rs](../../../tools/ai-tuner/src/ai.rs) の choose_move / Params
- 盤・ルール：[src/board.rs](../../../tools/ai-tuner/src/board.rs)
- WASM：[src/wasm.rs](../../../tools/ai-tuner/src/wasm.rs) の ai_choose

WASM のラッパーでは depth=0 が v1 を選ぶ API 上の指定です。「0 手先の方式」という意味ではありません。同じ係数と乱数条件を与えた JS / Rust / WASM の選択手を照合しています。

v1 はコミを着手選択に使いません。そのため、同じ棋譜の終局得点からコミ別勝率を再計算できます。死に石の除去を含まないアプリの面積ルールでの評価です。

## 係数セット

| 識別子 | 内容 | コード上の名前 |
| --- | --- | --- |
| v1-original | 調整前の手作業の重み | ai::Params::legacy |
| v1-tuned-20261020 | 自己対局で調整した重み。比較・検証用 | ai::Params::tuned / AI_WEIGHTS |

係数の変更は v1 内の実験として記録します。`legacy` / `tuned` はツール内部の別名であり、単独ではアーキテクチャを特定しません。
