# Kyokugo AI v2

Kyokugo AI v2 は、候補手を限定した alpha-beta 探索で、自分と相手の着手を合わせて最大 4 手先まで読むアーキテクチャです。

## 探索と評価

[src/search.rs](../../../tools/ai-tuner/src/search.rs) が実装です。

- ルートは上位 12 候補、その後は上位 6 候補を調べ、各節点でパスも含めます。
- 取り、アタリの救出・捕獲、呼吸点、隣接石、自己アタリで候補の順位を付けます。
- 非終局では盤上の石、距離 1〜3 の勢力、呼吸点の少ない連の危険度、コミを評価します。
- 終局ではアプリの実得点を使い、勝ち・引き分け・負けを区別します。勝敗の基準値は ±10,000、引き分けは 0 です。
- 合法手・自殺手・位置的スーパーコウは共通の Rust Game で検証します。

石の静的評価 1、取りの候補優先度 12、ルートの乱数幅 0.05 を基準とし、13 個の可変係数を Params / BOUNDS に定義しています。終局の勝敗にコミを使うため、コミ別の評価は実際に対局し直します。

候補を落とす探索なので全合法手の最適性は保証しません。深い死活や人間に対する棋力を保証するものでもありません。

## 係数セットと配信構成

| 識別子 | 内容 | コード上の名前 |
| --- | --- | --- |
| v2-original | v2 導入時の手作業の係数 | search::Params::legacy |
| v2-tuned-20261021 | 静的評価の係数を調整した最終候補 | search::Params::tuned |
| v2-deployed-20261021 | トーラス 7×7／9×9 に調整値を採用し、他の盤は初期係数を使う配信構成 | search::Params::for_points |

13 係数を同時に調整した最初の候補は、盤・相手への過適合が見つかり採用していません。最終候補は候補順位の 8 係数を初期値に固定し、静的評価の 5 係数を探索したものです。探索・採用の詳細と全候補は [調整実験](../../../experiments/ai/v2/2026-10-21-tuning/README.md) に保存しています。

今後の再調整にも新しい係数セット ID と実験 ID を付けます。係数セットの新旧を v1 / v2 と呼びません。

## API と比較実験の呼び方

WASM の ai_search は深さ 1〜4 を受け取ります。アプリは深さ 4 を使います。深さ 1〜3 の試走も v2 の評価関数・探索実装による条件です。

search-tune の `legacy` は v2-original、`tuned` は v2 の全盤共通の候補、`deployed` は盤別採用構成、`greedy` は v1-tuned-20261020 を指します。従来の CLI 別名と保存データは互換性のため維持します。
